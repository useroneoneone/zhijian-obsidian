# 知间 · Knowledge Studio

给 Obsidian 知识库一个可以阅读、整理与继续思考的空间。界面以六类知识分区组织笔记，提供阅读书架、状态筛选、书签、阅读足迹和笔记关联图谱。

**作者的 Obsidian 知识库采用 Andrej Karpathy（卡帕西）的 LLM Wiki 知识库架构。** 原始资料、持续维护的 Markdown Wiki 与维护规范分别承担来源、知识页面与 schema 的职责；具体目录结合作者的六类知识分区。架构原始说明见 [Karpathy · LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)。知间为这套工作流提供本地阅读和知识管理界面，LLM 的摄入、问答与维护由知识库自己的 Agent 工作流完成。项目作者：Y。

默认使用**星夜深色**主题；右上角可以切换为**冰蓝浅色**。背景使用 WebGL 流场、Canvas 粒子与 CSS 3D 卡片交互，所有资源随插件打包。WebGL 不可用时会显示 CSS 背景。

## 安装与打开

安装运行只需要三个文件：`main.js`、`manifest.json`、`styles.css`。开发源码和构建工具不参与插件运行。

在「设置 → 第三方插件」中启用「知间 · Knowledge Studio」；若界面提示受限模式，通过该设置页正常开启第三方插件，然后用 `Ctrl/Cmd + P` 搜索「打开知间知识工作台」。

1. 在知识库中创建 `.obsidian/plugins/zhijian-studio/`。
2. 将上述三个文件放入该目录。
3. 重启 Obsidian 或重新加载插件列表，在「设置 → 第三方插件」中启用「知间 · Knowledge Studio」。
4. 点击左侧工作台图标，或在命令面板执行「打开知间知识工作台」。另有「在右侧栏打开知间」命令。

插件声明的最低 Obsidian 版本为 `1.5.0`。用户提供的 Obsidian 截图已确认插件可显示首页；完整读写与交互仍需在实际知识库中验收。离线预览使用示例数据；原生插件通过 Obsidian API 读取当前知识库。

`1.1.1` 修复了宿主按钮样式导致的统计文字错位和轮换卡片长文本溢出。更新时覆盖三个运行文件，再关闭并重新启用插件。插件设置保存在独立的 `data.json` 中。

## 日常使用

- **概览 / 阅读书架**：查看摘要、分类和阅读状态，切换卡片或列表显示。
- **首页布局**：笔记总量与合并的阅读进度各占一张统计卡；阅读足迹占两张卡的宽度，三张面板等高，全年十二个月份与周格对齐。点击「正在阅读」或「已完成阅读」可分别筛选书架。轮换卡片右侧为等高的知识沉淀面板，书架使用整个内容宽度。
- **首页 3D 轮播**：三张真实笔记每 3.5 秒自动交换前后景位置，切换过渡 700 毫秒；标题和阅读入口跟随前景卡片。悬停、键盘聚焦或切到后台时暂停，支持箭头、指示点和暂停按钮。
- **页面工具**：所有页签都将搜索、主题及设置放在「记录新想法」上方，直接从页面标题开始。搜索检索当前列表的标题、标签、摘要和目录，工作台中可用 `Ctrl/Cmd + K` 定位搜索框。
- **六类分区**：项目、资产、资源、辅助、灵感与 Skills；分类优先匹配目录，其次参考 YAML `type`。
- **笔记详情**：读取 Markdown 正文，设置阅读及吸收状态，也可以在 Obsidian 编辑器中打开原笔记。
- **待沉淀**：只展示「已读」且「待沉淀」的笔记。
- **我的书签**：点击卡片右下角的书签按钮。书签及界面设置保存到插件自己的 `data.json`。
- **知识图谱**：采用与 Obsidian 图谱相近的点线网络及力导向布局。连接越多，节点越大；悬停时突出相邻笔记，点击节点打开详情。可拖动节点、拖动空白平移、滚轮或按钮缩放、点击靶心适应画布。键盘 `+` / `-` 缩放，`0` 适应大小，方向键平移；左下角也可通过笔记选择器定位节点。六种颜色对应六类知识分区，支持分区筛选和显示/隐藏孤立笔记。连线来自双向链接和 `related` / `关联` 属性，原生索引通过 Obsidian 链接解析器处理同名及相对链接。原生插件另有「打开原生图谱」入口。

单次图谱最多展示 1000 个节点，超出时显示提示；可以用搜索或分区筛选缩小范围。图谱使用本地 Canvas 及力导向模拟，没有外部运行依赖；模拟稳定后停止物理计算，保留很轻的慢速漂浮。关闭图谱时清理交互与绘制资源。

每次打开知识图谱，先准备视野，再播放约 **3.2 秒**的水中生长动画。节点逐个从中心加入真实的力导向模拟；新节点的斥力与连接会轻推已有节点，带着阻尼和惯性缓缓让位。连线始终跟随端点，节点全部出现后沿原来的运动继续平缓收敛，稳定后保留约 1–2 像素的低频漂浮。生长到稳定的全过程保持镜头不变，避免完成时再次扩散。名称渐显后保持相对节点的方向，不因每帧避让而跳位或闪烁。

动画中也支持精确拖动节点；手动缩放、平移或适应画布不重播。离开图谱后再次进入会重新播放。完整标题可通过悬停或定位查看。

### 主题与动效

点击右上角设置按钮，或打开 Obsidian 的知间插件设置，可调整名称、主题、动效与排除路径。

| 设置值 | 表现 |
| --- | --- |
| `full` | 完整流场、纵深粒子与 3D 悬浮效果；默认值 |
| `subtle` | 减少粒子与运动幅度，保留轻柔的空间感 |
| `off` | 停止连续动效，使用静态背景 |

系统的「减少动态效果」偏好优先生效。页面隐藏时会暂停绘制，关闭工作台时会释放相关资源。
关闭动效或使用系统减少动态效果时，首页保留手动轮换，图谱直接显示完整布局。

## 与知识库的关系

默认识别以下目录。已有笔记无需批量迁移；不在这些目录中的笔记可通过 `type` 归类，没有匹配时归入辅助。

| 分区 | 目录 | YAML `type` |
| --- | --- | --- |
| 项目 | `01-项目` | `project` |
| 资产 | `02-资产` | `asset` |
| 资源 | `03-资源` | `resource`，也识别 `source-summary` |
| 辅助 | `04-辅助` | `support` |
| 灵感 | `05-灵感` | `idea` |
| Skills | `06-Skills` | `skill` |

### 索引范围与原始资料

- 默认排除 `04-辅助/私密`；设置中每行可添加一个知识库相对路径。排除是界面索引范围设置，不会移动或删除文件。
- 自动跳过 `.obsidian`、`.git`、`.trash`、`node_modules`，路径名称包含「模板」或匹配 `template` / `templates` 规则的内容，以及 `README.md`、`AGENTS.md`、`CLAUDE.md`、`index.md`、`log.md` 等系统文件。
- `03-资源/原始资料` 保持只读：知间可以展示正文、添加书签，但不在此目录内创建笔记或修改阅读与吸收状态。这个保护适用于知间界面，不会改变文件权限。
- 浏览、检索和刷新只建立索引。状态变更与「保存想法」是实际写入知识库的操作。

### 阅读与吸收状态

详情中的状态变更使用 Obsidian `processFrontMatter` 更新对应 YAML 字段，保留其他属性与正文。

```yaml
阅读状态: 在读  # 未读 / 在读 / 已读
吸收状态: 待沉淀  # 待沉淀 / 已沉淀 / 无需沉淀
开始阅读: 2026-10-03
完成阅读: 2026-10-03
状态更新时间: 2026-10-03
```

首次进入「在读」或「已读」时记录相应日期，已有完成日期会保留。阅读足迹依据完成日期统计；知识沉淀进度以已读且需要沉淀的笔记为基数。

### 新建笔记与维护记录

「记录新想法」在所选分区创建 `<标题>.md`，补齐以下 YAML schema：

```yaml
id: idea-20261003-一个新想法-示例标识
title: 一个新想法
type: idea
status: incubating
created: 2026-10-03
updated: 2026-10-03
tags: [灵感]
sources: []
related: ["[[index|知识库总索引]]"]
阅读状态: 未读
吸收状态: 待沉淀
```

`id` 按分区、日期、标题与路径生成；资源的 `status` 为 `reference`，灵感为 `incubating`，其他类型为 `active`。输入正文中的旧 frontmatter 会移除，避免覆盖新页面的 schema。

创建后会在根目录 `index.md` 的对应分区插入链接，并向 `log.md` 追加创建记录；缺少这两个文件时会创建。已有同名页面会提示选择新标题，不覆盖旧文件。如果页面创建成功但索引或日志更新失败，会保留新页面、显示具体路径和错误，供后续补充记录。

## 离线浏览器预览

交付包相邻的 `preview/index.html` 可直接打开。请保持 `preview` 与 `zhijian-obsidian` 两个目录相邻。

安装了 Node.js 时，也可以在本插件目录执行 `node ../preview-server.mjs`，然后打开 `http://127.0.0.1:4177/preview/index.html`。交付包根目录另有 `start-preview.cmd`。这个服务只读取交付文件，绑定本机回环地址。

预览包含 20 篇原创中文示例笔记，更改只存入当前浏览器的 `localStorage`；右下角「重置」恢复示例内容。预览不连接真实 Obsidian 知识库，「在 Obsidian 中打开」会显示示例提示。

## 从源码构建

开发需要 Node.js 18 或更高版本。唯一构建依赖固定为 `esbuild` **0.28.2**，锁文件随包提供。

在本目录执行：

```sh
npm ci --ignore-scripts
npm run build
```

`build.mjs` 将 `src/plugin.js` 及本地模块打包为 CommonJS `main.js`，目标为 ES2020。只有 `obsidian` 被保留为外部运行时依赖，由 Obsidian 自身提供。脚本在写入前检查外部依赖，并将 Phosphor 图标许可证写入生成文件。构建不改写 `manifest.json` 或 `styles.css`。

| 源文件 | 用途 |
| --- | --- |
| `src/plugin.js` | Obsidian 视图、事件、文件操作及适配器 |
| `core.js` | 分区、排除规则、状态及页面 schema |
| `ui.js` | 原生与预览共享界面 |
| `fx.js` | WebGL 流场、Canvas 粒子与交互动效 |
| `graph.js` | 点线渲染、力导向模拟、拖拽、缩放与键盘图谱交互 |
| `fluid.js` | 增量节点出生、Barnes–Hut 斥力、弹簧、碰撞与水阻尼 |
| `carousel.js` | 首页 3D 轮换、手动控制、暂停与计时器清理 |
| `icons.js` | 内置 Phosphor SVG 图标 |
| `styles.css` | 双主题与响应式样式 |

调整源码后重新构建，再复制三个安装文件到插件目录并重新加载插件。仅修改样式时可直接替换 `styles.css`。
